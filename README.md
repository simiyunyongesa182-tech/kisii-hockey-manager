# 🏑 Kisii Hockey Manager

A mobile-first team management system for Kisii University Hockey Team. Players check in via phone at training, coach tracks attendance live.

### 🎯 Problem it solves
Coaches use books at the field to write attendance. Players say "I was there but you didn't mark me". No record of who is serious for lineup.

### ✅ Solution
- Player opens app -> sees Today's Training (Main Pitch, 4:30 PM)
- Clicks **CHECK IN NOW** when he arrives at field
- System records time automatically, attendance becomes 18/22
- Coach dashboard shows live: 18 Present, 2 Late, 2 Absent, calls absentees
- End of month stats to select serious players for fixtures

### 🚀 Features
- Role-based login: Coach, Captain, Player (Reg No + Password)
- Training scheduling & calendar
- One-tap check-in with timestamp
- Live attendance stats
- Fixtures management vs other universities
- WhatsApp reminder to absentees
- Mobile friendly - works on cheap Android phones

### 🛠️ Tech Stack
- Frontend: React / HTML / Tailwind CSS
- Backend: PHP / Node.js compatible
- Database: MySQL / LocalStorage for demo
- Hosting: Replit + GitHub
